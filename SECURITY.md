# Security policy

pi-wt runs inside pi with your user permissions and executes `git` and shell commands in your repositories.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/RebliNk17/pi-wt/security/advisories/new), not in public issues. You should get a reply within a week.

## Supported versions

Only the latest release receives fixes.
